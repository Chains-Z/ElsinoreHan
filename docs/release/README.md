# Elsinore 中文汉化补丁使用说明

汉化补丁版本：1.0.0
内部版本：1.5.15（用于技术排查，与汉化补丁版本分别编号）

适用于 Windows 版《Elsinore》1.4.1（3678），支持 64 位 Windows。需要自行拥有并安装游戏。

## 怎么安装

先退出游戏，把压缩包里的全部文件解压到 Elsinore.exe 所在的文件夹，然后照常从 Steam 启动游戏。详细步骤见[安装方法](INSTALL.md)。

## 常用按键

- F8：中文、英文原文互相切换，再按一次恢复中文。
- 长按左右任意 Ctrl 约 1 秒：跳过正在播放的演职人员名单，右下角圆环填满后生效。原有空格快进仍可使用。
- Alt+R：重新载入本地译文。更新整个补丁后请退出并重新启动游戏。

补丁完全离线，不需要联网翻译，也不需要填写密钥。

## 翻译与反馈

翻译：GPT-6.1-sol；校对：GPT-6.1-sol 与项目作者（Chains-Z）。

已经人工游玩所有路线，应该没有重大翻译错误，但不代表已穷尽所有已知对白，也不保证每句对白都经过逐句校对。

包含对白、人物资料、文档、线索、日志、地图和时间线等文字，以及中文字体。译文以机器翻译初稿为基础，结合实际游玩持续校订，尚未对所有分支逐句人工校对；可能仍有错译、漏译或文字显示问题。工作人员姓名、歌曲名、品牌等部分内容保留原文。

遇到问题请看[常见问题](TROUBLESHOOTING.md)。本版变化见[更新说明](CHANGELOG.md)。
