# 发布说明

## v1.0.0（首个公开版本）

适用于 Windows 版《Elsinore》1.4.1（3678），支持 64 位 Windows。本版将现有中文补丁整理为首个公开版本，提供解压即用的完整包。

- 翻译：GPT-6.1-sol；校对：GPT-6.1-sol 与项目作者（Chains-Z）。
- 已经人工游玩所有路线，应该没有重大翻译错误，但不代表已穷尽所有已知对白，也不保证每句对白都经过逐句校对。
- 提供 17,069 条预制译文和 157 条动态文字规则，覆盖对白、人物资料、文档、日志、线索、地图和时间线等文字。
- 提供中文字体与 F8 中英文切换，内部兼容插件版本为 1.5.15。
- 新增演职人员名单跳过功能：长按左右任意 Ctrl 约 1 秒即可跳过，保留原有空格快进。
- 对外汉化补丁版本为 1.0.0，内部版本为 1.5.15，分别维护。
- 原创代码与配套技术文档采用LGPL-2.1或更高版本，随包附上插件对应源码和构建说明，欢迎通过项目仓库共同维护。
- 根据实际游玩反馈持续校订对白、人物称呼及后期文本，统一同一句话在不同显示格式下的译文。
- 修正多项阅读界面的文字组合、滚动位置与显示问题，并改善片尾文字处理的停顿。
- 支持解压到游戏目录即用，并提供可选的安装检查与保守卸载工具、第三方许可及对应源码材料。
- 运行时完全使用离线词表，无需在线翻译服务或 API Key。

译文以机器翻译初稿为基础，已有实际游玩校订，尚未对所有分支逐句人工校对。其他系统、游戏版本及模组组合未验证；未知动态文字、图片文字及部分长文排版仍可能需要继续修正。此包不包含游戏本体、玩家存档或存档恢复功能。

首次安装、更新或卸载前请完整退出游戏，操作步骤见 [INSTALL.md](INSTALL.md)。遇到问题请参照 [TROUBLESHOOTING.md](TROUBLESHOOTING.md) 提供信息，公开反馈请标明剧透。
