# 故障排查与反馈

## 辅助安装或卸载被拒绝

- **游戏仍在运行**：保存并完全退出对应游戏，再重试。安装器不会替你关闭游戏；如果无法确认同名进程属于哪个目录，也会保守停止。
- **未找到游戏**：应选择直接包含 `Elsinore.exe` 的目录，而非 Steam 库、存档目录或补丁包目录。
- **包文件缺失或校验失败**：重新获取并完整解压同一版本的补丁包。不要混用不同版本的 `manifest.json`、脚本和运行文件。
- **目标文件发生冲突或已修改**：保存错误信息，核对是否安装其他模组或手动编辑过配置。安装器不会覆盖无法确认归属的文件。不要删除整个加载器目录；如需协助，请附冲突的相对路径及错误提示。
- **目录不可写**：检查游戏目录的访问权限。脚本不会自动申请管理员权限。
- **目录包含链接或重解析点**：安装器会拒绝此类目标。请在普通实际目录中安装游戏并重试。

卸载后留下加载器文件可能是保护其他模组的正常结果：直接解压安装没有归属记录，或安装后加入其他模组、修改共享依赖及配置时，卸载器会保留共享运行环境。请查看逐项报告，不要直接删除整个 `BepInEx/` 目录。

## 启动后仍是英文，或 F8 无反应

先确认完整解压了补丁，`winhttp.dll`、`doorstop_config.ini` 和 `BepInEx/` 与 `Elsinore.exe` 同级，没有多套一层文件夹。确认启动的是同一目录下的游戏，再完全退出并重新启动。核对游戏是否为已验证的 Windows 32 位 1.4.1（3678）版本。如果曾临时停用加载器，请检查 `doorstop_config.ini` 的 `[General]` 中 `enabled` 是否已恢复为 `true`。

若仍失败，请保留游戏目录下的 `BepInEx/LogOutput.log`，按本文末尾说明反馈。不要为了启用汉化填写翻译服务或 API Key；本补丁已配置为离线读取词表。

## 有方框、文字重叠、截断或漏译

重新启动游戏，确认安装没有报错。按 F8 对照英文，记录出现问题的界面、说话人和触发方式，并分别截图中文与英文。更新字体或配置需要重启；Alt+R 仅重载本地词表。

本版未逐一验证所有剧情分支和显示组合。歌曲名、工作人员姓名、品牌和按键等保留英文的内容不一定是漏译；请结合具体画面反馈。

## 想恢复纯英文

F8 可切换当前显示语言。若希望停用整个补丁或移除文件，请按 [INSTALL.md](INSTALL.md) 操作；Steam 的验证游戏文件功能不负责清理由模组新增的全部文件。

## 反馈问题

通过[项目仓库](https://github.com/Chains-Z/ElsinoreHan)提交问题时，尽量提供：

- 补丁版本、游戏版本，以及是否使用其他模组。
- 实际问题及最短复现步骤，包括说话人、界面名称或触发位置。
- 错译问题的英文原句、当前中文，以及按 F8 切换前后的截图。
- 启动或安装问题的完整报错；必要时附 `BepInEx/LogOutput.log` 中相关段落。

含剧情的标题、截图和正文请标明剧透，避免在标题直接写出结局内容。公开发送日志和截图前请遮盖用户名、本机路径等个人信息，不要发送密钥或账号信息。通常无需提交存档；若确需存档协助，应先另行确认范围。
