# 常见问题

## 我的电脑是64位，能用吗？

能。本补丁适用于 Windows 版《Elsinore》1.4.1（3678），已在64位 Windows 上验证。游戏程序本身是32位，不代表只能用32位电脑。

## 装完还是英文，或 F8 没反应

先完全退出游戏，检查是不是多套了一层文件夹。winhttp.dll、doorstop_config.ini 和 BepInEx 文件夹必须与 Elsinore.exe 放在一起。确认启动的是这个文件夹里的游戏，再重新启动。

如果仍有问题，请通过下方仓库反馈。不要自行填写在线翻译服务或密钥。

## 有方框、文字重叠、截断或漏译

先重新启动游戏。按 F8 对照英文，分别截下中英文画面，记下说话人、界面位置和触发步骤。工作人员姓名、歌曲名或品牌保留英文不一定是漏译。

## 安装或卸载工具报错

- 提示游戏正在运行：保存并退出游戏后重试。
- 提示找不到游戏：请选择能直接看到 Elsinore.exe 的文件夹。
- 提示文件缺失或校验失败：重新下载并完整解压同一个版本的补丁，不要混用新旧文件。
- 提示文件冲突或被修改：保留提示并反馈，不要随意删除其他模组文件。
- 提示没有权限：检查游戏目录是否允许当前用户写入；工具不会自动申请管理员权限。

卸载后留下部分通用文件，可能是为了保护其他模组。请按提示处理，不要删除整个 BepInEx 文件夹。
