## 保留与排除

裸源 `I do.` 在多种简短应答中共享，幽灵变体按该场景译为“是的，我也一样。”；不强制覆盖所有情境。前句为否定时，中文的“是的”也可能承接该否定，不能只看单句判为反义。

幽灵编译新增的整段斜体只剥离一层用于比较，保留原句内部的强调范围。纯停顿及没有进入当前程序集的旧场景不补词条；尾部空白单独记录。既有历史阶段证据保持原样。

Wittenberg此次仅把同一英文句的两版统一为“威登堡”，未处理其他独立句中的地名差异。

## 防止再次单边漂移

`tools/translation/audit_source_variants.py` 默认只读检查：成对源及双译文均绑定SHA256；任一端改变后，旧的允许差异记录即失效。显式运行别名独立核对基本词条；真实编译源缺失不能被旧场景排除吞掉。只有完成逐项审查后才使用 `--write-reviewed-baseline`。审定记录在 `translation/supplemental/source-variant-reviewed-differences.json`。

新专项层保留每条准确旧值、源哈希与真实场景出处。84项消费者由人工审定的21组目标构建，并验证真实角色姓名、资源／编译源、对话框封套及日志。7份既有夹具的79项预期值仅按同源及精确旧译同步，测试输入不变。
