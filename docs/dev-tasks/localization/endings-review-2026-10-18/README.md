以下不擅自替作者改剧情或填空：

- 婚姻线开场婚日与三个月后祭坛的叙事跳转、和平线父兄留下而结尾泛称死者，按原文保留。
- 弃争结局概括众人死亡后又提到少数幸存者，不为消除源文自己的张力改写事件。
- `sunlight shines through her`原文含“透过她”的光照意象；不凭中文的奇异感改成只照在她身上，更不补成幽灵身份。
- `feel my body in full relief`在身体舒适和归属语境里有解释空间，现译放松可成立，不在无充分依据时强行换另一解读。
- `long purples`的文学植物称呼没有据不确定的植物辨认改名；既有长穗紫兰保留。[皇家莎士比亚剧团的排练记录](https://www.rsc.org.uk/hamlet/past-productions/in-focus-gregory-doran-2008)描述了高高的紫色花穗，但不足以据此为本译文指定唯一学名。

这些保留并不意味着没有其它可选译法。逐段审查以能说明的语义偏差为修改依据，不将个人偏好的不同写法全部判作错译。
