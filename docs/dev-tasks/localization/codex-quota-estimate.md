# 全文翻译和 AI 校对的 Codex 额度估算

2026-10-09。用户确认当前为每月 200 美元、20× Pro。以下只作任务预算，不声称查询过账户余额或实际订阅扣率，也不开始全量翻译。百炼 API 的 1 元扩大样本费用与 Codex 订阅额度分开。

## 本地文本和计算假设

静态主候选 15,153 条，194,856 英文词、1,017,168 字符，另有 1,036 条程序集字符串待审核。示例按全文一遍 **50 万非缓存输入 token + 50 万输出 token** 计算；这不是精确分词结果，也未包含全部工具、推理、重复读取和再校对。应按场景分批，保持短上下文，不用一个长对话重复承载全文。

## 官方计价口径

[官方 Codex/Work 点数说明](https://learn.chatgpt.com/docs/pricing) 的 Standard 每百万输入/输出分别为：GPT-6 Luna 2.5/12.5 点、GPT-6.1 Sol 50/250 点、GPT-5.6 Terra 50/300 点。该示例分别为 **7.5、150、175 点**。购买点数的 Fast 口径为两倍；套餐内含额度使用不同倍率，官方明确不能只用点数价格推断订阅容量。

[官方 API 单价](https://developers.openai.com/api/docs/pricing) 的 Standard 示例中，GPT-6 Luna 的输入/输出为 0.1/0.5 美元每百万，Sol为 2/10，Astra为 10/50。示例分别折算为 **0.3、6、30 美元** API 等价用量。这不是让用户额外购买 OpenAI API，不能当本任务实际费用。

当前 agent 工具可直接选择 GPT-6 Luna；没有 Terra 子agent调用选项。公开 API 模型可存在，与本会话可选模型不同。

## 用户要求的社区测量

- [2026-10-04 的详细日志测量](https://inventivehq.com/blog/codex-subscription-usage-measured)：作者的新 200 美元 **10×** 套餐在两个窗口测得约 640–670 美元/周的 Standard API 等价用量；旧 **20×** 的约 1,300 美元/周是按倍数推算，并非同样实测。其编码工作负载约 96% 输入命中缓存，10× 对应约 9,200 万非缓存输入加输出或 21 亿含缓存 token；不能用这个含缓存数字直接除全文译文字数。作者明确 Luna 权重尚未可靠测量。
- [20× 用户同账户日志报告](https://github.com/openai/codex/issues/43731)：2026-09不同模型区间外推的 Standard API 等价周容量不同，约 1,925 美元的旧Sol与 1,234 美元的Astra；作者明确未排除其他设备、自动审核、倍率等因素。此报告是用户观测，不是 OpenAI 承诺或已证实的计费问题。
- [近期 Reddit 测量贴](https://www.reddit.com/r/codex/comments/1wuokuj/i_measured_my_200_codex_plan/) 的含缓存 token 数和模型切换体验差异很大，不用其中某个总 token 数作为固定套餐上限。

若暂用 20× **1,300 美元/周**的社区推算作为换算基准，示例理论比例：Luna约0.02%、Sol约0.5%、Astra约2.3%。这是跨来源的外推，Luna订阅权重尤其没有得到同程度实测。缓存、输出占比、实际模型/速度及账号其他活动都会影响结果。

对用户的实际建议：若采用Sol、短上下文及低到中等思考处理一遍全文，先按 **周额度2%–5%作工作预算**，为普通开销和局部复核留余量，随后用本账户同一周窗口的额度变化校准。这是主agent的保守预算建议，不是社区测出来的翻译消耗或保证上限；复杂剧情复核、多轮全篇改写不在该预算承诺内。

## Luna 校对试验

已让不继承会话的 GPT-6 Luna 独立核对旧 40 条 DeepSeek Flash 真实译文，没有调用百炼或重译源文。它提出 5 项修订，见[原提案](../../../translation/trial-expanded-2026-10-09/luna-review-probe.json)和[主agent复核](../../../translation/trial-expanded-2026-10-09/luna-review-assessment.json)。

有用的提案包括去除重复表达、识别witching hour的直译风险；也有把“眼睛空了”改成“眼睛里面空空的”仍未解决歧义、给肯定原句擅加“听说”等问题，且漏掉God forbid惯用否认。因此可以用它先发现问题并给出候选改法，不能把提案自动覆盖原译文或宣称“AI审过就无需复核”。本试验没有观察到可归因的账户额度扣减，不虚报节省百分比。
