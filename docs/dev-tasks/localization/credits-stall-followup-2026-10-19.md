# 片尾圆环在长帧后直接跳满

状态：1.5.14已通过隔离对照并经安装器安装，同时合入幽灵悔恨的两条最终译文；当前无待安装修改。用户先要求继续游玩、仅做离线检查，随后退出游戏并授权验证后安装。见[完整候选核验](../../../runtime/evidence/credits-stall-verification-2026-10-19.json)及[安装核验](../../../runtime/evidence/credits-stall-install-verification-2026-10-19.json)。

## 问题与修改

用户在提示出现后按住Ctrl，圆环正常增长到约半圈，画面停顿后直接跳满退出。1.5.13只保护初次显示就绪的时机，手势类仍按“当前实时时间减去按下时刻”计算进度；中途两次更新之间间隔过长，会一次跨过完成门槛。

1.5.14改为逐次累计相邻有效采样的时间差，每次最多计入0.1秒，即10%圆环。正常刷新约1秒完成；卡顿或很低帧率时延长，继续显示剩余进度。加载时不累计、预按须释放、松开／失焦清零、时钟回退重新计时、满环后延迟一帧退出的规则保留。原空格快进、音乐、保存与结局条件不变。

这项修改解决长间隔后直接补满的计时行为。玩家那次停顿的具体来源仍未定位，未宣称消除底层主线程或渲染卡顿。
