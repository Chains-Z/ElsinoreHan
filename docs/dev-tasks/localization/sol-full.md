## 文风与校订

普通对白使用自然、易读的现代中文，仅保留原文已有的古雅、戏剧感和人物差异；祈祷、诗句和戏中戏适度凝练，不统一译成文言。否定、时间状态、亲属关系、传闻及可能性按本游戏原句处理，人物性别以游戏证据为准。

原始响应不覆盖。发现的一处多余斜体标签已修正，原句和理由在 local-corrections.json；一条带花括号的自然句子曾被校验器误判为变量，修复校验后原译文直接回收。后台 UI 的测试乱码保留原始响应，列在 excluded-nontext.json，不加入正式词表。这些恢复没有新增模型调用。

英文残留检查只有一项：《Das Buch von guter Speise》的德文书名，同时已有中文书名《美食之书》，属于保留专名。格式和完整性检查不能证明每句话的含义正确。

游戏中遇到疑句可按 F8 核对原文，记录英文句子和问题即可定位词表；修改后按 Alt+R 重新加载。F8 使用插件缓存的原句，不从中文反向生成英文。
