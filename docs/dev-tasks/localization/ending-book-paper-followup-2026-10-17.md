# 命运书页补块、偏位与翻页层级修复

状态：1.5.8候选已完成，尚未安装；[候选证明](../../../runtime/evidence/ending-book-paper-verification-2026-10-17.json)。正式游戏仍为1.5.7，用户截图已确认该版书页存在视觉缺陷，旧阶段的组件通过记录不改写为视觉验收。

## 根因与方案

1.5.7以2041×1322的裁剪图定位到原生2048×1400书页Image，忽略Sprite的裁剪偏移，导致遮盖区域与新增文字一起偏位，英文残留。取自另一块纸面的矩形产生明显色差；新增层又作为BookBG的最后子物体，越过了原Page Turning卷页图，造成用户截图中的悬浮文字。

1.5.8移除全部BookLabelCover图形，不再用纸面补块。只读玩家游戏中已绑定哈希的DXT5书页，在内存中解码重建：检测英文笔画并扩展2像素，仅对8,336个掩码像素内的RGB做四邻域插值。实际7,208像素变化，其余像素和全部透明度字节不变。新Sprite与原Sprite的完整矩形、轴心、PPU一致；原资源文件不写入，也不打包游戏图片。

新增TMP与真实关键词放在同一个EndingUnlockDialog下，服从原卷页图层顺序。列中心取原生关键词，行中心按完整1400高纹理定位。关键词保留60号粗体，连接词改为48号斜体并沿用原生墨色，减少突兀感。F8显示原Sprite、隐藏新增层，恢复中文时使用内存重建纹理。

准确源契约见[书页来源](../../../translation/supplemental/ending-book-paper-source.json)。解码或来源不符时保留原背景，不对未知版本盲目擦字。正文、动态词表、字体、许可和配置均未变化。
