## 保留与共享源保护

`He loves her more than anything in this world.`在码头场景同时用于哥哥对妹妹的亲情和哈姆雷特对女主的爱情，保留能兼容两者的“爱”，不改成限定关系的疼爱妹妹。霍拉旭明确的恋爱表白、哈姆雷特“某种意义上，我确实爱你。但不是那种爱”的区分均保留，未因同性关系而泛化成友谊。“我爱你，父亲”等自然亲情和“爱你们的仇敌”等引文也保留。
