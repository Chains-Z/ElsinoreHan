# F8切换时保留日志底部

## 问题与修复

用户在中文日志末尾查看格蕾丝19:08教匕首的对白，按F8后英文跳到17:23的船员闲聊，滚动条也向上移动。不能将此现象解释为滚动条未变、仅换行不同。

旧 `LogScrollAnchor` 总是保护视口上沿的硬换行段落。中文已经在末尾时，英文内容高度增加，保住同一上沿段落仍会使英文末尾落在视口外。段落恢复报告 `restored` 因而不能证明仍在日志底部。

插件1.5.5在每次F8前捕获是否距底部不超过1个UI单位；若是，等待翻译与布局稳定后回到底部。其余位置沿用段落锚点。阈值使用实际距离，避免在很长的日志中按固定百分比把用户主动上滚的位置误判为底部。文档阅读路径不变，不持续吸附，也不锁住手动滚动。原有历史、控件及generation失效检查保留。
