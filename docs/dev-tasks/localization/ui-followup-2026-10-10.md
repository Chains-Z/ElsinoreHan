# 游玩反馈：线索、地图与时间线

2026-10-10。用户截图显示多段线索正文、地图确认及时间线详情仍有漏译，并指出嵌套信念通知读起来生硬。本轮只修这些实际消费路径，复用冻结译文，不重跑全文或调用模型。

## 修复与来源

- 线索：`GuiUtils.FormatLeadText` 将真实生效且未过时段落以两个换行拼接；`UiStrings.SetTextWithLineHeight` 再包行高。原单换行拆分不能完整消费这些组合，编译器的九步破折号替换又产生18个精确源变体。新增20组限定拆分和18个别名，保留原资源、冻结响应、译文及段落顺序。136段的同组组合、字段内部双换行和未知段落拒绝均由独立期望校验。
- 地图：`Go to {0}?` 已有译文，但去掉参数后只有7个字符，被通用格式规则的长度门槛过滤。新增真实显示值白名单，覆盖31个房间和46个人物；包括截图的 `Upper Hallway` 与 `Hamlet`。不翻内部ID或未知参数。
- 时间线：真实无 `Changes` 的已参加事件仍追加空行高段距；旧规则不能消费空尾。房间白名单漏掉原词表已覆盖的 `Gertrude's Chambers`；通知末换行规则又会抢先剥掉未参加事件句子的精确冻结源换行。新增6条限定规则修复完整标题、名单及空尾，不补写剧情。
- 嵌套信念：两层“相信”在汉语中成立，但照搬后生硬。外层改为“现在认为，”，内层仍用“相信”；截图译为“贝尔纳多现在认为，奥菲莉娅相信‘自己身处危险’。”，实际双引号和粗体按原文保留。只有内层信念主体与命题主体确实相同的已审危险信息才用“自己”，不添加“以为”等真假倾向。

源证据分别在 `analysis/ui-audit/lead-followup-il.json`、`map-confirmation-source-evidence.json`、`timeline-followup-source-audit.json`。修订、来源及拒绝用例在 `translation/supplemental/*followup*` 和 `map-ui-*`；导出后16,861条译文、121条规则（24格式、97限定UI），插件仍为1.3.0。

## 探针修正

时间线的 `ActiveModalControl` 优先返回自己的 `EventInfoPopup`，因此同时核对当前Timeline画布、精确弹窗身份、激活状态和正文归属，不能要求直接等于Timeline，也不能允许任意弹窗。未参加或未来事件不调用 `Details`；已参加事件确实缺scene记录时只记录明确的 `KeyNotFound` 来源并跳过，不能把缺记录伪装成零Changes。最初详情恢复使用原事件真实按钮。

反射调用改为准确参数签名：`FormatTimeString` 有字符串返回和builder两种重载，不能只按名字取方法。真实DLL离线检查13个签名，并用真实 `GameClock` 纯逻辑核对五个截图日期，复现旧六小时偏差；该纪元从06:00起，日期getter统一加360分钟。历史循环的索引从当前0向过去递增，Previous使索引加1，Next减1；恢复必须采用真实按钮并比对最初完整源。
