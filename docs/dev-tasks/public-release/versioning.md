# 对外版本与内部版本

2026-10-19按用户要求拆分版本：对外汉化补丁版本为 **1.0.0**，内部兼容插件版本保留 **1.5.15**。此前将内部版本和日期拼接为公开标签的方式停用，原发布及核验记录保留为历史证据。

## 维护约定

- 唯一版本配置为 `tools/release/version.json`：`patch_version` 表示整个汉化补丁的公开版本，`internal_version` 表示兼容插件版本。
- 两者独立递增。译文、字体、配置或发行内容变化可以单独发布新补丁；只有兼容插件发生变化时才调整内部版本，不要求两个版本相等。
- GitHub 标签为 `v<patch_version>`，附件名为 `ElsinoreHan-v<patch_version>-windows.zip`。包内 `ElsinoreHan/manifest.json` 同时记录两个版本；`release_id` 沿用安装器兼容字段，值为公开标签。
- 构建时校验版本格式，并将内部版本与正式安装证明及 `BepInPlugin` 声明交叉核对，防止仅改元数据而错误标注组件版本。
- 发布时同步玩家说明、更新日志、反馈模板及 GitHub 发布说明。用户通常报告公开版本，内部版本供技术排查使用。
