## 安装器契约

依据用户后续明确偏好，公开包运行文件平铺于根目录，解压到 `Elsinore.exe` 旁即可使用。`ElsinoreHan/` 包含 `Install.cmd`、`Uninstall.cmd`、`install.ps1`、`uninstall.ps1`、`common.ps1`、`manifest.json`，由父目录读取运行文件。命令参数为 `-GamePath`。双击命令脚本后输入目录；不提权、不联网、不做备份。已有模组/升级时建议先解压到外部目录，辅助安装器核对冲突。

辅助安装器通过 `ElsinoreHan.install.json` 记录自有文件及其哈希。共享文件不认领，未知冲突停止；卸载仅删除自有且未修改文件，保留已修改文件与残余记录。直接解压无记录时，仅按当前manifest准确哈希移除6项项目独有文件，通用加载器/翻译依赖/配置保留。不会整体删除加载器目录，不影响原游戏四文件或玩家存档。
